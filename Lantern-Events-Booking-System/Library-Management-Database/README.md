Library Management Database

A relational database designed for managing library operations.

Features

- Member management
- Library staff management
- Loans and returns
- Fines management
- Inter-library loans
- Bibliographic records

Database Design

This project includes:

- Logical Data Model
- Physical Data Model
- Entity Relationships
- Referential Integrity Constraints
