# Smart Locker System

## Overview

A Python console application that simulates a smart locker storage service.

The system allows customers to:

- Store luggage
- Retrieve luggage
- Make payments
- Generate receipts
- Recover forgotten passcodes
- Earn loyalty discounts
- View account activity

## Features

- Menu-driven interface
- Input validation
- Exception handling
- Locker allocation
- Mobile number authentication
- Passcode recovery
- Loyalty reward system
- Digital receipts
- Activity logging
